# Sicherheitsmeldungen

Bitte melde Sicherheitslücken nicht öffentlich als Issue. Verwende GitHub Security Advisories für eine private Meldung, sofern private Meldungen für dieses Repository aktiviert sind.

Die Weboberfläche hat keine eigene Anmeldung und muss auf `127.0.0.1` beschränkt bleiben. Öffne den Zugriff über einen SSH-Tunnel und veröffentliche Port 8080 nicht direkt im Internet.
