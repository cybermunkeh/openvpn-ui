# Änderungen

## 0.2.0

- OpenVPN UI im SolidState-IT-Design überarbeitet.
- Separate Firewall-/UFW-Verwaltungsoberfläche und deren API entfernt.
- Installer- und Funktionsumfang für die automatische Linux-Installation dokumentiert.

## 0.1.0

- Erstes eigenständiges Linux-Paket mit Weboberfläche, Backend, systemd-Dienst und Installer.
- Installer unterstützt systemd-Systeme mit apt, dnf, yum oder zypper.
- Weboberfläche bindet standardmäßig nur an localhost.
